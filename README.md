# OpenArena

Open-source AI model battle arena.

OpenArena lets users compare open-source AI models through blind side-by-side battles and community voting.

## Vision

- Blind model-vs-model battles
- Community-driven ELO rankings
- Open model registry
- Category leaderboards
- Public battle history
- API-first architecture

## Status

🚧 Early development

## Planned stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Redis
- Model provider adapters
